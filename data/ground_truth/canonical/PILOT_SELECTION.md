# Pilot Ground Truth Selection

The pilot evaluation set was selected before quantitative
page-level OCR evaluation.

## Page 0002 — Structured document layout

Selected to represent structured administrative material.

Features include:
- distribution lists
- a separate Copies column
- abbreviations
- names and locations
- numerical values
- security markings

## Page 0004 — Prose

Selected to represent predominantly continuous prose and
paragraph-style typewritten text.

This page provides a comparison with the highly structured
layout of page 0002.

## Page 0006 — Degraded typewritten characters

Selected to represent character-level degradation.

In particular, some capital letter A forms have weak or missing
horizontal strokes, creating a potentially systematic OCR
recognition problem.

The page was selected to test OCR robustness to degraded
typewritten glyph forms.
